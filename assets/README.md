# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

## Images

Store reusable source images and generated display assets in `images/`.

| File | Dimensions and format | Use and source |
| --- | --- | --- |

Generated for this repository with the built-in image generation tool on 2026-09-17; the six labels and values were checked against the documented hardware contract. |
| [`images/logo-wordmark.png`](images/logo-wordmark.png) | 1648 × 336, PNG RGBA | Transparent black wordmark extracted from the repository's original `images/logo.png`; embedded in the bilingual hardware overview under `docs/README` for light backgrounds. |
| [`images/logo-wordmark-dark.png`](images/logo-wordmark-dark.png) | 1648 × 336, PNG RGBA | White version of the extracted wordmark, used by the hardware overview `<picture>` element when GitHub is in dark mode. |

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.

## Queen Reborn BGM assets

- `music/playlist.json`: the six current display titles and playback order;
  `01.wav` through `06.wav` contain the imported excerpts. Provenance, trims
  and actual WAV hashes are in `music/sources.json`. Reference downloads are
  optional local provenance and ignored by Git. See [music sources](music/README.md)
  for recordings and durations. Redistribution permission is unverified.
- `main/bgm_tracks_data.c` and its JSON report: generated by
  `python3 tools/pack_bgm.py --require-all`; 16 kHz mono, decoded as 16-bit PCM
  from 4-bit IMA ADPCM, streamed in 512-sample chunks.
- `fonts/NotoSansCJKsc-Regular.otf`: from the official
  [Noto CJK repository](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf),
  under the SIL Open Font License 1.1, retained in `fonts/OFL.txt`.
- `fonts/bgm_font_12.c`, `bgm_font_16.c`, `bgm_font_20.c`: uncompressed 4-bpp
  subsets, generated with LVGL's `lv_font_conv` 1.5.3. Character inventory is
  `fonts/bgm_chars.txt`; the glyph list is `fonts/bgm_glyphs.h`.
  Regenerate with `python3 tools/generate_bgm_fonts.py --converter <lv_font_conv>`.
  The application explicitly selects these fonts and checks every code point
  and a known absent negative case. On-device acceptance checks Chinese rendering in all widgets.
