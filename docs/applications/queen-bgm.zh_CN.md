# 重生之我是女王 BGM

播放器开机直接进入黑金色 240 x 320 界面。共享项目标题定义在
`main/queen_bgm.h`。启动默认暂停、第 1 首、音量 45%、单曲循环，不提供 demo
菜单或返回操作。标题字体为 16 像素，长按说明占一排。

## 播放行为

上/下切换上一首/下一首，首尾环绕；长按以 10 为步长调音量，范围 0-100%。
OK 播放/暂停并保留进度，长按 OK 切换单曲循环/播放一次，双击无操作。
播放中切歌从新曲开头开始，播放设置在开机时重置。

20 秒无操作时背光降至 15%，操作后恢复 70%。暂停休眠 codec，继续播放时安全
恢复音频格式。界面显示曲名、序号、时间、进度、音量、电量与模式。

## 音乐与字体

[音乐来源表](../../assets/music/README.zh_CN.md)列明六首录音和原始截取位置。
WAV 片段合计 164.6405 秒，16 kHz 单声道 IMA ADPCM 在 Flash 中占
1,317,124 字节。`assets/music/playlist.json` 定义歌名与顺序；
`assets/music/sources.json` 记录来源页面、版本、截取位置和哈希。
WAV 已完成裁剪，所有配置 start 均为 0。

```bash
python3 tools/pack_bgm.py --require-all
```

打包需要 Python 3 与 FFmpeg，限峰、添加短淡入淡出后编码为 4 位 IMA ADPCM。
工具拒绝超过 5 MiB 的音频；固件门禁验证完整 8 MB 布局。发布构建要求六个输入
文件齐全。仓库中的音频和字体 C 源码支持正常构建，无需下载音源或安装字体转换器。

Noto Sans CJK SC 的 12、16、20 像素子集覆盖固定界面与歌名。创建页面时逐字符
检查覆盖，并验证已知缺字的反向用例。修改标题需使用 1.5.3 版 LVGL 字体转换器：

```bash
python3 tools/generate_bgm_fonts.py --converter <lv_font_conv路径>
python3 tools/pack_bgm.py --require-all
./tools/validate.sh
```

## 程序结构

`main/main.c` 初始化显示与按键、创建播放页并启动任务。按键回调只入队、不阻塞。
音频任务独占状态、codec、音量与 PCM，从 Flash 每块解码 512 个采样。任务栈
为 8 KiB，独占静态 1 KiB PCM 缓冲并复用于结束静音。编译器限制函数栈帧不超过
512 字节，播放日志记录任务最小剩余栈。

显示任务读取状态快照并持 LVGL 锁短暂更新。两个任务确认停止后才能删除队列、
句柄或页面；超时保留所有权并支持重试。固件不链接无线栈与硬件测试页，保留
NVS/PHY/factory 分区布局，播放不写入持久设置。

## 验证与固件

`./tools/validate.sh` 执行仓库检查、主机测试、全新 ESP-IDF 构建、合并镜像校验
与匹配的调试归档。主机测试覆盖播放状态、ADPCM 标准向量、分块边界、六文件
打包、任务创建失败、停止时序、重试与页面所有权。

真机验收覆盖开机直达、中文显示、播放暂停、切歌、循环模式、双击无操作、音量
边界、电量与长时间播放。构建结果与设备结果分别记录。
